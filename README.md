# 🛒 বাজার দর | Bazar Dor

Bazar Dor is a responsive web application that helps users explore daily essential product prices in Bangladesh, track price changes, and compare market prices easily.

🔗 **Live Website:** [Bazar Dor](https://bazar-dor-omega-ten.vercel.app/)

## ✨ Features

- 📊 View daily essential product prices.
- 📈 Track increasing and decreasing prices.
- 🗂️ Browse products by category.
- ↕️ Sort products by price.
- 🔍 View product details and market price information.
- 🔐 Sign in and sign up with email/password and social authentication.
- 👤 View profile and update user information.
- 📱 Responsive design for mobile, tablet, and desktop.
- 🔔 Toast notifications and loading skeletons.
- 🚫 Custom 404 page for invalid routes.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth
- REST API
- React Hot Toast
- Vercel

## 🚀 Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ProgrammingHero1/B14-A7-Bazar-Dor.git
```

### 2. Navigate to the Project Folder

```bash
cd B14-A7-Bazar-Dor
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add the required environment variables for authentication, database access, and other services used by the project.

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 6. Build for Production

```bash
npm run build
```
